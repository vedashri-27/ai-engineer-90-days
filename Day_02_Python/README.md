## 🔁 Loop Concepts

### for loop

Used to iterate through a sequence of values.

### while loop

Used to repeat code while a condition is true.

### range()

Used to generate a sequence of numbers.

### enumerate()

Used to get both the index and value while looping.

### break

Stops the loop.

### continue

Skips the current iteration and continues with the next one.

### Nested loops

A loop inside another loop.

## 📦 Collections

| Collection | Example | Mutable | Duplicates |
|---|---|---|---|
| List | [1, 2, 3] | Yes | Yes |
| Tuple | (1, 2, 3) | No | Yes |
| Set | {1, 2, 3} | Yes | No |
| Dictionary | {"name": "John"} | Yes | Keys are unique |
